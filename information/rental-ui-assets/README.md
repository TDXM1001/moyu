## 建议尺寸与颜色

- 设计基准：750 px 宽移动端画布。
- 主要橙色：`#F28A00`；辅助金橙：`#E5A039`；正文深色：`#202020`；次级灰：`#747474`。
- TabBar：使用 `tabbar-states-transparent-sprite.png` 裁切；文字请对应设置为 `#F28A00` / `#757575`。
