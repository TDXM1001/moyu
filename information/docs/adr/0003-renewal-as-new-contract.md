# 续租是新建一份关联的合同，不是修改原合同的到期日期

续租时系统新建一份"待生效"的新合同，记录"续租自哪一份旧合同"，但不提前结束旧合同。旧合同到了约定到期日后，仍由管理员确认实际结束，再标记为"已结束"（终止原因：到期结束）；如果旧合同还没结束，新合同即使到了起租日也不能开始。系统不直接修改原合同的到期日期。

直接改日期实现起来更简单，但会让"这个租户从入住到现在租金涨了几次、每次租期多长"这类历史信息被不断覆盖、无法复原。续租时租金、押付方式经常会变，选择新建关联合同，代价是多了一次记录动作和一条"续租自"的关联字段，换来的是每一段租期的真实条款都完整保留，回头查历史时能看到完整的续租链条。保留旧合同到实际结束，也能保证历史记录中的结束时间是真实发生的，而不是因为提前点击续租就被改写。
