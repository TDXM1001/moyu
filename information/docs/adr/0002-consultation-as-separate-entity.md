# 咨询记录是独立实体，挂在"看房人+房源"这对关系上，不是房源的备注字段

新增"咨询记录"实体，规则是"一人一房一条"：系统在看房人点击咨询按钮时自动创建，后续同一人对同一房源的跟进都追加在这条记录里，不新建也不混进房源本身的字段。

之前的设计把跟进内容写成房源上的一个"跟进备注"文本字段，这在只有一个人问过的时候没问题，但同一套房源经常被多个人问，所有人的进展全部堆进同一个文本框会很快变得无法区分是谁说的什么。把咨询记录提升为独立实体，代价是多了一张表、多了一个管理页面，但换来的是"这个人对这套房源问到什么程度了"永远清晰可查，也让"看房人 → 咨询 → 签约成租户"这条链路第一次在数据结构上有了完整的落点，而不是只能靠管理员脑子记着谁问过什么。
