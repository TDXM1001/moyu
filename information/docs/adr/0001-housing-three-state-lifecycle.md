# 房源与合同都用三态生命周期，而不是简单的"占用/空闲"二态

房源状态用"可以租 / 已预定 / 已租出"三态，合同状态用"待生效 / 生效中 / 已结束"三态。系统会按起租日期检查待生效合同是否可以开始，但到期日不会自动结束合同；管理员确认实际结束后，房源状态再根据所有合同重新计算。

选择三态而不是"可以租/已租出"二态，是因为签约和实际入住之间存在真实的时间差：合同签了但租户还没搬进来，这段时间房子实际是空的，但已经不能再对外展示。如果用二态，这段时间要么被误标成"已租出"，要么被误标成"可以租"，都会造成判断错误。三态把"签了没入住"和"真实在住"分开；同时，合同到期也不能只靠日期自动关闭，因为系统无法替管理员确认租户是否真的搬走，必须保留人工确认这一步。
